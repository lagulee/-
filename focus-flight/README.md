# ✈️ Focus Flight

비행 콘셉트의 Windows 집중 타이머입니다. 목적지를 고르면 실제 거리로 집중 시간이 정해지고,
허용 목록 밖의 창으로 이탈하면 **난기류**가, 오래 머무르면 **추락**이 일어납니다.
지정한 YouTube 플레이리스트는 예외로 들을 수 있습니다.

## 가장 쉬운 실행 방법 (Windows)

1. **[여기를 눌러 최신 버전 페이지로 이동](https://github.com/lagulee/-/releases/latest)**
2. **`FocusFlight-Portable.exe`** 를 눌러 내려받기
3. 내려받은 파일을 **더블클릭** → 끝!

- 설치가 필요 없습니다. 시작 메뉴에 등록하고 싶으면 `FocusFlight-Setup.exe`를 받으세요.
- "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. (코드 서명이 없어서 뜨는 경고입니다)
- 창을 닫으면 시계 옆 트레이로 숨습니다. 완전히 끄려면 트레이 아이콘 우클릭 → **종료**.

## 휴대폰 웹 버전 (설치 없음)

1. 휴대폰 브라우저(Chrome, 삼성 인터넷, Safari)에서 **https://lagulee.github.io/-/** 열기
2. 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 아이콘으로 실행

- 비행 중 Focus Flight 화면을 벗어나면(다른 앱·탭) 난기류, 10초 넘게 안 돌아오면 추락합니다.
- 웹은 화면 꺼짐과 앱 전환을 구분할 수 없어 **화면을 끄는 것도 이탈**입니다. 대신 비행 중에는 화면이 저절로 꺼지지 않습니다.
- 기록은 그 브라우저에만 저장됩니다.

## 안드로이드 휴대폰에서 실행 (APK)

1. 휴대폰에서 **[최신 버전 페이지](https://github.com/lagulee/-/releases/latest)** 를 열고 **`FocusFlight-Android.apk`** 를 눌러 내려받기
2. 내려받은 파일을 눌러 설치 — "출처를 알 수 없는 앱" 설치를 허용하라는 화면이 나오면 허용
3. 앱을 열고 **설정 탭 → 사용 기록 접근 허용하러 가기** → 목록에서 **Focus Flight** 허용
4. **알림 허용**도 눌러 두면, 비행 중 다른 앱을 쓸 때 "⚠️ 난기류! n초 안에 돌아오세요" 알림이 뜹니다
5. 설정 탭의 **허용 앱**에서 비행 중 써도 되는 앱(예: 사전, 메모)을 체크

- 홈 화면·알림창을 보거나 **화면을 끄는 것은 이탈이 아닙니다.** 음악 앱은 백그라운드 재생만 하면 고르지 않아도 됩니다.
- 사용 기록 권한을 주지 않으면 Focus Flight 화면을 벗어나는 것 자체를 이탈로 봅니다.
- 기록은 휴대폰 안에만 저장되고 PC와는 따로입니다.
- 새 버전 APK를 같은 방법으로 설치하면 기록을 유지한 채 업데이트됩니다.

## 개발자용 실행

```bash
cd focus-flight
npm install
npm run dev      # Electron 개발 모드 (Windows)
npm test         # 단위 테스트
npm run web      # Electron 없이 브라우저에서 화면만 미리 보기 (가상 활성 창으로 테스트)
npm run dist     # Windows 설치 파일(.exe) 생성 → dist/
```

## 동작 방식

| 단계 | 설명 |
|---|---|
| 예약 | 전 세계 125개 공항 중 출발·도착 선택. 지도는 휠로 확대·끌어서 이동, 도시 색은 집중 시간대(~30분 / ~1시간 / ~2시간 / ~4시간 / 4시간+). haversine 거리 `d` → 집중 시간 `t = k · d / v` (k=0.5, v=850 km/h, 10~360분) |
| 탑승 | 5초 카운트다운 후 이륙 |
| 비행 | 활주로 가속 → 이륙 → 상승 → 순항 → 하강 → 착륙을 3D로 보여 줍니다. 시점은 **3인칭 / 조종석 / 창가석 / 지도** 중 선택. 1초마다 활성 창을 확인 |
| 난기류 | 비허용 창이 2초 이상 이어지면 발생. 화면 위에 경고 오버레이(클릭 통과) |
| 추락 | 난기류 10초 초과, 또는 비행 포기. 마일리지 절반 |
| 착륙 | 여권 도장 + 마일리지 `m = 10 · t^1.2` (t: 분). 마일리지로 기종 해금 |

- 일시정지: 비행당 2회, 1회 최대 5분 (넘으면 자동 재개)
- 시스템 창(작업 표시줄, Alt+Tab, 시작 메뉴, UAC)은 위반으로 보지 않고, Focus Flight 창을 보는 것은 집중으로 칩니다.
- 브라우저 확장이 없으면 창 제목에 허용 사이트 이름(예: Notion, GitHub)이 있는지로 짐작합니다. 난기류 경고에 지금 창이 왜 비허용인지 표시됩니다.
- 비행 중에는 허용 목록을 넓히거나 규칙을 바꿀 수 없습니다.
- 모든 값은 설정 화면에서 조정할 수 있습니다.

## 플레이리스트만 허용하기 (브라우저 확장)

브라우저 창 제목만으로는 어떤 영상인지 정확히 알 수 없어서, 작은 확장 프로그램이 현재 탭 URL을 앱에 알려 줍니다.

1. Chrome/Edge/Whale에서 `chrome://extensions` (Edge는 `edge://extensions`) 열기
2. **개발자 모드** 켜기 → **압축해제된 확장 프로그램 로드** → `focus-flight/extension` 폴더 선택
3. 앱 설정의 **플레이리스트**에 YouTube 플레이리스트 링크를 붙여 넣기

확장이 연결되면 URL에 `list=<지정한 ID>`가 있는 페이지만 허용되고, 같은 YouTube라도 다른 영상·쇼츠는 차단됩니다.
확장이 없을 때는 **창 제목 키워드**(예: 플레이리스트 이름)로 근사합니다.

확장은 `ws://127.0.0.1:47321`로만 통신하며, 앱은 확장(`chrome-extension://`) origin의 연결만 받습니다.

## 한계

- 앱 자체를 종료하면 막을 수 없습니다. 강제 차단이 아닌 자기 약속 도구입니다.
- 다른 앱을 강제 종료하지 않습니다 (저장하지 않은 작업 보호).
- 데이터는 `%APPDATA%/focus-flight/focus-flight.json`에만 저장되고 외부로 전송되지 않습니다.
