# ✈️ Focus Flight

비행 콘셉트의 Windows 집중 타이머입니다. 목적지를 고르면 실제 거리로 집중 시간이 정해지고,
허용 목록 밖의 창으로 이탈하면 **난기류**가, 오래 머무르면 **추락**이 일어납니다.
지정한 YouTube 플레이리스트는 예외로 들을 수 있습니다.

## 실행

```bash
cd focus-flight
npm install
npm run dev      # Electron 개발 모드 (Windows)
npm test         # 단위 테스트
npm run web      # Electron 없이 브라우저에서 화면만 미리 보기 (가상 활성 창으로 테스트)
npm run dist     # Windows 설치 파일(.exe) 생성 → dist/
```

## 동작 방식

| 단계 | 설명 |
|---|---|
| 예약 | 출발·도착 도시 선택 → haversine 거리 `d` → 집중 시간 `t = k · d / v` (k=0.5, v=850 km/h, 10~180분) |
| 탑승 | 5초 카운트다운 후 이륙 |
| 비행 | 1초마다 활성 창을 확인. 지도 위 비행기가 대원 경로(slerp)를 따라 이동 |
| 난기류 | 비허용 창이 2초 이상 이어지면 발생. 화면 위에 경고 오버레이(클릭 통과) |
| 추락 | 난기류 10초 초과, 또는 비행 포기. 마일리지 절반 |
| 착륙 | 여권 도장 + 마일리지 `m = 10 · t^1.2` (t: 분). 마일리지로 기종 해금 |

- 일시정지: 비행당 2회, 1회 최대 5분 (넘으면 자동 재개)
- 시스템 창(작업 표시줄, Alt+Tab, 시작 메뉴, UAC)은 위반으로 보지 않습니다.
- 비행 중에는 허용 목록을 넓히거나 규칙을 바꿀 수 없습니다.
- 모든 값은 설정 화면에서 조정할 수 있습니다.

## 플레이리스트만 허용하기 (브라우저 확장)

브라우저 창 제목만으로는 어떤 영상인지 정확히 알 수 없어서, 작은 확장 프로그램이 현재 탭 URL을 앱에 알려 줍니다.

1. Chrome/Edge/Whale에서 `chrome://extensions` (Edge는 `edge://extensions`) 열기
2. **개발자 모드** 켜기 → **압축해제된 확장 프로그램 로드** → `focus-flight/extension` 폴더 선택
3. 앱 설정의 **플레이리스트**에 YouTube 플레이리스트 링크를 붙여 넣기

확장이 연결되면 URL에 `list=<지정한 ID>`가 있는 페이지만 허용되고, 같은 YouTube라도 다른 영상·쇼츠는 차단됩니다.
확장이 없을 때는 **창 제목 키워드**(예: 플레이리스트 이름)로 근사합니다.

확장은 `ws://127.0.0.1:47321`로만 통신하며, 앱은 확장(`chrome-extension://`) origin의 연결만 받습니다.

## 한계

- 앱 자체를 종료하면 막을 수 없습니다. 강제 차단이 아닌 자기 약속 도구입니다.
- 다른 앱을 강제 종료하지 않습니다 (저장하지 않은 작업 보호).
- 데이터는 `%APPDATA%/focus-flight/focus-flight.json`에만 저장되고 외부로 전송되지 않습니다.
